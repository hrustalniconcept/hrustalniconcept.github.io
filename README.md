## Как править

Тексты, цены, сроки, кейсы и отзывы лежат в `content/`, код их не содержит:

- `content/services.json` — данные услуг: цены, сроки, состав, этапы, FAQ, SEO, фото.
- `content/cases.json` — кейсы в формате Ситуация → Что нашли → Что поменяли → Что изменилось.
- `content/config.json` — контакты, вебхук Битрикс24, номер счётчика Метрики, ссылка на пример отчёта, политика.

После правки пересобрать страницы:

```bash
python3 tools/build.py
```

Генератор собирает `uslugi/**/index.html`, `sitemap.xml`, `robots.txt` и `CONTENT-TODO.md` со всеми заглушками `[[ЗАПОЛНИТЬ: ...]]`, которые встретил в данных. Заглушки видны на страницах пунктирной рамкой до тех пор, пока не заполнены.

Фото: `python3 tools/build_assets.py <исходник.jpg> <имя> [--crop l,t,r,b]` кладёт webp в трёх размерах в `assets/img/uslugi/`, затем имя указывается в `image.src` услуги.

## Источники контента

Пакет `docs/services-pack/` (прайс, состав, FAQ, кейсы), рабочий стандарт бюро v2.0 и протокол диагностики продаж (блоки, гейты, артефакты, метрики). Цены только из пакета; расхождения со стандартом собраны в разделе «Решения» файла `CONTENT-TODO.md`.

## Стек

HTML + CSS + немного JS, без фреймворков. Шрифты Inter и Bebas Neue (с кириллицей, как на hrustalni.com) подключены локально. Дизайн-код: `docs/brand_style_standard.json`. Пакет исходных материалов: `docs/services-pack/`.

Форма отправляет лид в Битрикс24 через входящий вебхук (`crm.lead.add`) с UTM-метками, услугой и страницей отправки. Пока вебхук не задан в `config.json`, форма работает в тестовом режиме и печатает заявку в консоль браузера.
