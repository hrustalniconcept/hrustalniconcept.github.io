# Пакет материалов для сборки раздела «Услуги»

Концепт-бюро «Хрустальный», hrustalni.com. Сентябрь 2026.

## Как этим пользоваться

Положить всю папку в корень репозитория сайта, в `/docs/services-pack/`. Читать в этом порядке:

1. `00-PROMT.md` — задание. С него начинать.
2. `brand/brand_style_standard.json` — действующий дизайн-код. Источник истины по цвету, шрифту, сетке.
3. `01-voice.md` — как писать. Соблюдать дословно, это не рекомендации.
4. `content/services.json` — данные пяти услуг. Правится без правки кода.
5. `content/cases.md` — кейсы. Только то, что подтверждено.
6. `02-audience.md` — кому продаём и на какой стадии.
7. `03-facts.md` — цифры, которые можно публиковать, и статус каждой.
8. `04-tech.md` — интеграции, метрики, SEO, доступность.
9. `content/CONTENT-TODO.md` — чего пока нет. Дополнять по ходу работы.

## Правило номер один

В этих файлах нет ни одной выдуманной цифры. Всё, чего здесь нет, выдумывать нельзя: ставить заглушку `[[ЗАПОЛНИТЬ: что именно нужно]]` и выносить её в `content/CONTENT-TODO.md` с указанием страницы и блока.

Отдельно: придуманных отзывов быть не должно даже в примерах кода и в моках.

## Статусы фактов

В файлах пакета у цифр стоят пометки:

- `[проверено]` — можно публиковать как есть.
- `[сверить]` — цифра взята из расшифровки аудио, в распознавании бывают ошибки. На сайт не выводить, пока не подтвердят.
- `[оценка]` — расчётная величина, публиковать только со словом «около» или «по нашему опыту».
- `[нет данных]` — заглушка.
